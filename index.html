Danh sách gói

Chọn gói để cài trực tiếp qua Sileo.

🔍

Ứng dụng (IPA)

Tải file .ipa để cài qua AltStore, Sideloadly hoặc TrollStore. Chỉ nên host app bạn có quyền phân phối (app gốc của bạn, mã nguồn mở, hoặc bản enterprise/ad-hoc hợp lệ).

🔍

Định dạng apps.json

Mỗi app trong mảng JSON gồm các field sau:

{
  "name": "Tên app",
  "bundleId": "com.example.app",
  "version": "1.0.0",
  "size": "45.0 MB",
  "category": "Tiện ích",
  "description": "Mô tả ngắn về chức năng của app.",
  "icon": "icons/com.example.app.png",
  "url": "ipa/App.ipa"
}

category và description là 2 field mới — dùng để nhóm app theo danh mục (hiện thành chip lọc phía trên) và hiển thị mô tả ngắn trên từng thẻ. generate_apps_json.py tự điền sẵn 2 field này rỗng vì IPA không chứa sẵn thông tin đó — bạn cần tự điền tay sau khi script chạy xong.

Tệp khác

Cấu hình, chứng chỉ, plist và các file hỗ trợ khác — mỗi file kèm mô tả để biết dùng vào việc gì trước khi tải.

🔍

Định dạng files.json

Mỗi tệp trong mảng JSON gồm các field sau:

{
  "name": "Tên tệp hiển thị",
  "extension": "mobileconfig",
  "type": "Cấu hình",
  "size": "4 KB",
  "description": "Mô tả dùng để làm gì, khi nào cần dùng.",
  "url": "files/example.mobileconfig"
}

type dùng để nhóm thành chip lọc phía trên (VD: Cấu hình, Chứng chỉ, Plist, Nén...). extension hiện thành badge màu trên góc thẻ thay cho icon app. Không có script tự sinh cho mục này — bạn tự viết tay files.json vì đây là file linh tinh, không có metadata chuẩn để đọc tự động như IPA/deb.
